    Manual

    What this tool does

    It reads a folder of RingIndicator output. Cores are grouped into trees by name: the last part of the name identifies the core, and everything before it is the tree. So KOR-014-A and KOR-014-B are two cores of tree KOR-014, and so are KOR-014-A2 and KOR-014-A3, or GHE-Q003-1 and GHE-Q003-2. For each tree the core that reaches furthest back in time (lowest indicated year) is opened; on an equal oldest year the higher number wins, so A3 is preferred to A2. Every core of the tree is listed beside the tree name, so one click switches to another. It shows the transverse preview <core>_Tv.tif, windowed to 200–1200 kg/m³, with the indication lines from <core>_ring_and_fibre.txt drawn on top. Your estimate is written to pith_offsets.xlsx in that same folder.

    The three cases

    1. Concentric circles (default). The core missed the pith. Circles are drawn around the cursor through each of the innermost indicated rings. Position the centre so the circles follow the curvature of the real rings and click. The saved offset is the perpendicular distance from that point to the innermost indicated ring — the same direction in which RingIndicator measures its tilt-corrected ring widths.
    2. Pith on the core. The pith is visible and already indicated, so the offset is 0 mm.
    3. Diameter & bark. The core is too short, or the centre has rotted, so no curvature is usable. Enter the single bark thickness and the tree diameter over bark at coring height (the ⌀/C button switches the field to circumference). The offset is then D/2 − bark − ΣRW/(1−Sr), where ΣRW is the accumulated indicated ring width of this core and Sr is the total green → oven-dry radial shrinkage of the species. The cores were oven dried, so this correction expands the measured widths back to their green size.

    Species and shrinkage

    Case 3 needs a species, for its radial shrinkage. Pick it once and it carries to the next tree, so a folder of one species is chosen once; the bark and diameter fields are always cleared between trees, because a carried-over diameter would be both wrong and invisible.

    The shipped Sr values are the CIRAD Tropix figures for temperate species. Every one is editable — Species table in the top bar — and whichever value was used is written into each saved row together with its source, so a row always says where its number came from. Edits are kept in pith_species_shrinkage.csv next to the data.

    Stopping and resuming

    Results are written after every save, to pith_offsets.xlsx and to pith_offsets.json beside it. Restart the tool on the same folder and it reopens at the first tree that has no result yet; finished trees are ticked in the list and can be reopened to overwrite.

    Output columns

    Distance_to_Pith_mm is the column to merge into your metadata — it is the one bakker_bai() wants. The rest of the row records how that number was reached: the method, the measured perpendicular and centre-to-centre distances, the diameter/bark/Sr inputs, the accumulated ring width both oven-dry and green, the pixel size, the clicked position, and a Flag column for results worth a second look.

    Species table — radial shrinkage

    Sr is the total green → oven-dry radial shrinkage as a fraction, used as RWgreen = RW / (1 − Sr). The shipped values are the CIRAD Tropix figures for temperate species. Add or correct rows as you need: whichever value a measurement used is written into its row in the spreadsheet along with the source text below, so it stays traceable. Anything you type in Source containing the word verify is flagged with a verify marker in the dropdown, which is a handy way to mark a number you are unsure of. Saving writes pith_species_shrinkage.csv next to your data.
